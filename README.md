# Ôn Tập & Phòng Thí Nghiệm 3D Hóa Học 8 (KHTN 8 - Kết Nối Tri Thức)

Ứng dụng web tương tác hỗ trợ ôn tập lý thuyết, trắc nghiệm, bài tập tự luận và thí nghiệm mô phỏng 3D cho chương trình Khoa học tự nhiên 8 (Phân môn Hóa học - Bài 2 đến Bài 12).

---

## 🚀 Tính năng nổi bật

- **Lý thuyết trọng tâm & Ảnh SGK sắc nét**: Tóm tắt kiến thức cốt lõi và tích hợp đầy đủ trang sách giáo khoa minh họa.
- **Phòng thí nghiệm 3D tương tác**: Mô phỏng trực quan các phản ứng hóa học (Three.js) như nhiệt phân, phản ứng tỏa nhiệt, phản ứng acid-base,...
- **Hệ thống trắc nghiệm & Tính điểm**: Luyện tập trắc nghiệm thông minh, giải thích đáp án chi tiết.
- **Công thức & Phương trình chuẩn hóa**: Hiển thị phương trình hóa học và công thức toán học sắc nét với KaTeX.
- **Giao diện hiện đại & Thân thiện**: Tối ưu hiển thị trên cả máy tính, máy tính bảng và điện thoại (Tailwind CSS, Lucide Icons).

---

## 🛠️ Hướng dẫn triển khai lên Vercel

1. Đăng nhập vào [Vercel](https://vercel.com).
2. Chọn **"Add New..."** > **"Project"**.
3. Kết nối với tài khoản GitHub và chọn kho lưu trữ `on-tap-chuong1-chuong2-khtn8`.
4. Tại phần **Framework Preset**, chọn **Other** (hoặc để mặc định).
5. Nhấn **Deploy** để hoàn tất triển khai.

---

## 💻 Chạy cục bộ (Localhost)

Bạn có thể chạy trực tiếp bằng bất kỳ máy chủ HTTP tĩnh nào:

```bash
# Sử dụng Python 3
python -m http.server 8080
```
Truy cập: `http://localhost:8080`
