    Khắc Phục Lỗi YouTube Error 153

    🔍 Vì sao bị lỗi Error 153?
    YouTube yêu cầu bắt buộc: Mọi video nhúng phải có Referrer / Origin hợp lệ từ máy chủ web. Khi mở tệp HTML trực tiếp bằng chuột (đường dẫn bắt đầu bằng file:///), trình duyệt không gửi thông tin này khiến YouTube chặn và báo "Video player configuration error Error 153".

    3 Cách Khắc Phục Triệt Để:

    CÁCH 1 (Khuyên dùng - 1 Click) Chạy file tự động CHAY-UNG-DUNG.bat

    Vào thư mục ứng dụng d:\APP-HOC-TAP\on-tap-hoa-8\ và nhấp đúp chuột vào tệp CHAY-UNG-DUNG.bat. Trình duyệt sẽ tự động mở http://localhost:8080 và phát toàn bộ 11 video thí nghiệm mượt mà ngay trong giao diện ứng dụng!

    CÁCH 2 Chạy lệnh qua Terminal / Command Prompt

    Mở PowerShell hoặc Command Prompt tại thư mục dự án và chạy một trong 2 lệnh sau:

    python -m http.server 8080
    node server.js

    Sau đó mở trình duyệt truy cập: http://localhost:8080

    CÁCH 3 Bấm "Xem trên YouTube ↗"

    Nếu mở trực tiếp từ file, bạn chỉ cần bấm nút đỏ "Xem trực tiếp trên YouTube ↗" ở dưới mỗi bài học để xem trọn vẹn video chất lượng cao kèm thuyết minh SGK.
